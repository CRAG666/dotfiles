# Quick Reference: Idiomatic Replacements

Canonical catalog of "AI-default" phrasing, padding, and filler, with acceptable substitutes. This is the single source of truth: add or change entries only here; `core-principles.md`, `academic-style.md`, and `qa-checklist.md` reference this file instead of duplicating it. Use during the final pass (see `SKILL.md` workflow step 6).

## AI-default phrasing

- **"Este artículo explora..."** -> "Este estudio examina...", "Este trabajo investiga...", "El objetivo de este estudio es...", "Este artículo aborda...", "El presente estudio se centra en...".
- **"Es importante notar que..."** -> "Cabe señalar que...", "Notablemente,", "Importante,", "Vale la pena señalar que...", o eliminar y afirmar directamente.
- **"Los resultados muestran que..."** (repetido) -> alternar con "Los hallazgos sugieren...", "Los datos indican...", "Se desprende de los resultados que...", "Los resultados ponen de manifiesto...", "Se evidencia que...".
- **"En conclusión,"** -> "Tomados en conjunto...", "En síntesis...", "A la luz de estos resultados...", "Estos hallazgos sugieren, en general,...", "En síntesis...".
- **"Como todos sabemos..."** -> eliminar; la ciencia no apela al lector de forma coloquial. Reemplazar con "Es ampliamente aceptado que..." o "Existe un consenso amplio de que..." con citación.
- **"Profundizar en..." / "Navegar por las complejidades de..."** -> "Examinar en detalle...", "Investigar a fondo...", "Abordar cuidadosamente...", "Analizar...".
- **"Un tapiz de..."** -> eliminar la metáfora; nombrar la mezcla o variedad real.
- **"En el ámbito de..."** -> "en", "dentro de".
- **"En el mundo actual..."** -> eliminar o reemplazar con una afirmación específica y citada.
- **"Una miríada de"** / **"Una plétora de"** -> "Una gama de", "Varios", "Numerosos", "Una variedad de".
- **"Muestra un entendimiento comprensivo de..."** -> "un entendimiento profundo de...", o nombrar lo que específicamente se entiende.
- **"Se puede ver que..."** (repetido) -> "Los datos muestran...", "X es evidente...", "Como se muestra en la Figura N,...".
- **"Este estudio pretende iluminar..."** -> "Este estudio examina...", "Este estudio investiga...".

## Padding constructions

Wordy constructions que añaden palabras sin significado:

- **"Con el fin de"** -> "para".
- **"Debido al hecho de que"** -> "porque".
- **"A pesar del hecho de que"** -> "aunque".
- **"Con respecto a" / "en relación a"** -> "respecto a", "en relación con", o reformular.
- **"Con el propósito de" + gerundio** -> infinitivo ("con el propósito de medir" -> "para medir").
- **"Debe señalarse que..."** -> eliminar, o afirmar directamente.
- **"Hay X estudios que han demostrado..."** -> "X estudios han demostrado...".
- **"El hecho de que"** -> reformular ("A pesar de que X" -> "Aunque X").
- **"Un gran número de"** -> "muchos".
- **"Un pequeño número de"** -> "pocos".
- **"Una amplia gama de"** -> "una gama de", o ser específico.
- **"En caso de que"** -> "si".
- **"En el momento presente"** -> "ahora", "en la actualidad".

## Vacuous intensifiers

"Muy", "realmente", "extremadamente", "absolutamente", "increíblemente", "totalmente", "completamente", "utteramente" -> eliminar, o elegir un adjetivo preciso. Ejemplos específicos:

- "muy importante" -> "central", "de importancia central", "fundamental"
- "muy grande" -> "sustancial", "considerable" (o un número)
- "muy diferente" -> "marcadamente diferente", "cualitativamente diferente"
- "muy pequeño" -> "negligible", "mínimo" (o un número)
- "realmente" -> eliminar
- "extremadamente alto" -> cuantificar
